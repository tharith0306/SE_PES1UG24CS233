# Lab 5: Reflection

## 1. What is static code analysis?

Static code analysis examines source code without executing the program.
It helps identify potential bugs, security vulnerabilities, and coding
standard violations.

## 2. What did Pylint, Bandit, and Flake8 identify?

Pylint was used to examine code quality.
Bandit was used to identify potentially insecure coding patterns.
Flake8 was used to identify style and formatting problems.

The actual findings are documented in issues.md.

## 3. What changes were made?

The code was modified to address the issues found during analysis.
The program was tested, and all three tools were run again to verify
the changes.

## 4. How does static analysis improve software quality?

Static analysis helps identify problems early, improves readability,
and encourages consistent coding practices. It complements testing
but does not replace it.
